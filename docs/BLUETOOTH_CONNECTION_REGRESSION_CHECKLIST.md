# 蓝牙连接回归清单

本清单用于两台 Android 设备，或 Android 手机与经典蓝牙 SPP 模块之间的验收。每次涉及连接层、权限、扫描、分帧、重连或后台行为的改动，都应按清单记录真实设备结果。

## 客户端流程

- [ ] 蓝牙关闭时打开应用，提示开启后可以继续初始化。
- [ ] Android 6–11 定位权限拒绝、重试、设置页返回路径均无崩溃。
- [ ] Android 12+ 扫描、连接、广播权限拒绝、重试、设置页返回路径均无崩溃。
- [ ] 连接或服务运行中撤销蓝牙权限后，Socket/线程安全收尾，重新授予权限后服务可重新初始化。
- [ ] 已配对设备和附近设备分组显示，重复广播不会产生重复条目。
- [ ] 点击未配对设备后，配对成功可以自动继续连接。
- [ ] 配对中或连接中点击“取消连接”，Socket、线程和状态都能收尾。
- [ ] 用户取消连接后状态为断开而非失败，且不会残留 UNKNOWN_ERROR。
- [ ] Socket 已建立但聊天页尚未打开时点击“取消连接”，不会迟到打开聊天页或留下活动会话。
- [ ] 快速连续点击同一设备只产生一次连接尝试。
- [ ] 连接成功后首页按钮进入会话，不再次发起连接。
- [ ] 无历史消息的设备从历史列表打开聊天页不崩溃，收发消息后列表正常插入并滚动。
- [ ] 长按设备资料可独立开关该设备自动重连，重新连接成功后开关状态保持。

## 收发与协议

- [ ] 文本发送与接收：UTF-8、GBK、ASCII。
- [ ] 设备编码选择为 HEX 时，非法输入明确提示并且不按文本编码发送。
- [ ] HEX 发送包含 `00`、高位字节和 1024 字节以上数据。
- [ ] CRLF/LF/CR、定长、自定义分隔符、超时分帧分别验证半包和粘包。
- [ ] 空帧、尾部残帧和超过上限的帧符合 Debug 页显示的规则。
- [ ] 普通发送与分片发送同时触发时，字节顺序不交叉。
- [ ] 分片发送可观察进度，取消后普通发送仍可继续。
- [ ] 分片发送在当前写入返回后取消时，不再继续发送后续分段。
- [ ] CRC/SUM/XOR 工具输出与远端工具或协议文档一致。
- [ ] 快捷宏的 TEXT、HEX、DELAY、重复执行顺序正确，且不写入消息历史。
- [ ] 宏执行后 Debug 日志可见、远端可收到，但历史聊天和设备摘要不新增宏消息。
- [ ] 快捷宏可通过系统文件选择器导出并导入到另一台设备资料，导入失败文件不会写入半条数据。

## 生命周期和后台

- [ ] 连接后切后台、锁屏、恢复前台，连接状态和会话仍正确。
- [ ] 旋转屏幕或重新创建 Activity，不产生重复连接或重复监听。
- [ ] 旋转屏幕或配置变更期间，进程级服务端 SPP 监听和现有客户端会话不中断。
- [ ] 同一 MAC 的并行客户端/服务端接入只保留一个会话，不重复打开聊天页，也不推进错误的重连尝试。
- [ ] 旋转屏幕或重新创建 Activity 时，原连接尝试仍可从首页查询并取消，不持有旧页面 Context。
- [ ] 旋转或返回后重新进入 Debug 页面，宏仍可执行，不复用已关闭的执行器。
- [ ] Debug 页面销毁后，迟到的收发/断开/分片回调不会崩溃或更新旧 View。
- [ ] 旧版或新版聊天页销毁后，迟到的收发/断开事件不会访问已销毁页面。
- [ ] 连续发送过程中旋转、返回或切换设备，线程可停止且不会访问旧 View 或把数据发到新设备。
- [ ] 远端断电后显示断开，并按 1/2/5/10/30 秒退避重连。
- [ ] 同一次重连同时出现超时和 Socket 异常时，只产生一个下一次退避任务。
- [ ] 连接超时后迟到的 Socket 异常不会重复 Toast、错误记录或推进重连。
- [ ] 旧重连线程迟到成功时，不会取消当前重连任务、覆盖有效会话或打开错误设备页面。
- [ ] 远端恢复后最多只有一个活动会话。
- [ ] 主动断开、关闭自动重连、退出应用后不会偷偷重连。
- [ ] 关闭全局或单设备自动重连时，已经在 Socket.connect 中的重连尝试也会停止；普通手动连接不被误取消。
- [ ] 关闭全局或单设备自动重连后，尚未执行的延迟重连任务也从 Handler 移除。
- [ ] 后台收到客户端或服务端连接时只发对应设备通知，不强制拉起聊天页。
- [ ] 点击通知后进入正确设备的会话。
- [ ] 从后台服务通知点击“断开当前连接”后，当前 Socket 和重连任务停止，但设备自动重连配置仍保留。
- [ ] 系统限制前台服务启动时，应用保持可用并记录错误，不发生 Activity 崩溃。
- [ ] 蓝牙关闭或通知栏主动断开时，当前聊天页收到断开事件并退出，Debug 页刷新连接选择器。
- [ ] 从旧版或新版聊天页主动退出后，首页状态为断开，连接不会残留在 Debug 设备选择器中。
- [ ] 多设备同时连接时，通知、历史、首页状态和 Debug 设备选择不串号。
- [ ] Debug 切换设备选择器后，日志、统计、宏、分帧配置和发送目标都只作用于所选 MAC。

## 统计、日志和退出

- [ ] Debug 页连接时长、收发字节、接收帧数、速率和错误数随真实流量变化。
- [ ] 诊断报告包含设备、MAC、UUID、状态、错误、重连、发送队列和结构化日志。
- [ ] 导出文本/HEX 日志包含方向、时间、MAC 和设备信息。
- [ ] Android 6–9 导出日志时可在系统文件选择器中选择目标目录；拒绝或取消选择不会崩溃，也不会误报导出成功。
- [ ] 关闭服务、返回首页、退出应用后服务端 Socket、客户端 Socket、接收线程均释放。
- [ ] 服务端快速停止后重启，旧 accept 线程不会关闭新服务 Socket 或新接入连接。
- [ ] 服务端接入后若远端元数据或页面交接失败，不残留活动 Socket，监听服务按预期收尾或可重新启动。
- [ ] 服务端 accept 线程异常停止后，回到前台能够自动恢复监听并继续接受新连接。
- [ ] 连接或服务运行中撤销蓝牙权限后，任意前台页面均能安全关闭 Socket/线程，重新授予权限后服务可重新初始化。
- [ ] 权限重新授予后，前台服务、消息监控和已启用设备的自动重连任务均恢复。
